## 开发

需要 Node 22 或更新版本。

| 命令 | 作用 |
|---|---|
| `npm ci` | 安装依赖 |
| `npm run check` | 类型检查 + 代码检查 + 自动测试（提交前必须通过） |
| `npm run dev` | 本地打开实验室页面 |
| `npm run build` | 构建到 `dist/`：`index.html`（GitHub Pages）、`standalone.html`（单文件）、`artifact.html`（claude.ai 测试链接） |
| `npm run bench` | 云端测速：一场比赛要算多久（加 `-- --variants` 看各部分占多少） |

代码结构：

- `src/core/`：比赛核心。必须逐位可重现：数学函数只用 `math.ts`，随机数只用 `rng.ts`，不碰任何浏览器或 Node 的接口（决策记录 D-005、D-006、D-012）。
- `src/proto/`：技术验证原型，用完就扔，阶段 1 写正式引擎时删除。
- `src/web/`：页面（实验室：确定性自检、测速、原型比赛画面）。
- `src/i18n/`：中英翻译表，界面文字都从这里取。
- `src/data/`：带版本号的数据格式和升级链（存档、世界数据、回放、反馈码都用它）。
- `tests/`：自动测试。`scripts/`：测速和构建后处理。
