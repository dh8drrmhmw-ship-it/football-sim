# 设计问卷第 2 批：能力值

发出：2026-11-02　状态：**等发起人回答**

这一批定下「球员有哪些能力、玩家怎么看到这些能力」。能力值是比赛引擎的输入：每一项都要对应到场上看得见的行为，不做只是摆着好看的数字。
这批问卷参考了品味清单里的两条：实况里的**招牌动作**（踩单车、双脚触球），和 FM **太数据化**的问题。

**怎么回答**：每题选一个字母。全部同意推荐就回复「全部按推荐」；只想改几题就写题号和字母，比如「2B 5C」。
每题都可以选「其他」并写上你的想法。这些以后都能改，但改得越晚越费事（第 1、6 题最难改，因为比赛引擎直接用它们）。

---

## 1. 能力项分得多细？

- **A. 场上球员 24 项 + 门将另有 7 项**（推荐，具体列表见文末附表）
- B. 36 项左右，和 FM 差不多细
- C. 12 项左右，像实况早期那样粗一点

推荐理由：每一项都要能在比赛里看出区别。24 项能把「传得准」和「看得到」、「跑得快」和「起步快」分开，又不会多到玩家记不住。FM 有些项（比如「天赋」「决断」「判断」）玩家自己都分不清有什么不同，我们不学。

## 2. 能力值怎么显示？（对应「FM 太数据化」）

- **A. 默认显示文字等级加颜色条（比如「出色」「良好」「一般」「薄弱」），设置里可以切换成 1～20 的数字**（推荐）
- B. 和 FM 一样，默认显示 1～20 的数字
- C. 和实况一样，用 1～100 的数字
- D. 完全不显示数字，只有文字描述（「传球精准，但很少冒险」）

推荐理由：默认一眼看出强项弱项，数字感少；喜欢精确的老玩家打开数字就行。电脑内部用更细的数，显示时才换算，不影响比赛。

## 3. 要不要一个「总评」？

- **A. 不给总评数字，用星级表示「在这个位置上、在你的队里算什么水平」**（推荐）
- B. 给一个总评数字（像 FIFA、实况的综合能力）
- C. 什么都不给，玩家自己看各项能力判断

推荐理由：一个总评数字会让大家只看这个数，又回到「太数据化」；而且同一个球员踢后腰和踢边锋水平不一样，一个数说不清。星级按位置算，还会随你球队的水平变（第三级球队的三星和顶级球队的三星不一样）。

## 4. 潜力（能长到多好）怎么显示？

- **A. 不显示具体数字，由教练组给一句模糊评价（「有望成为顶级联赛主力」），评价可能看走眼**（推荐）
- B. 显示一个潜力数字或星级，准确的
- C. 完全不显示，只能看他实际长得怎么样

推荐理由：保留「捡到宝」和「看走眼」的乐趣，这是青训和转会最好玩的地方。B 会让挑年轻球员变成查表。

## 5. 隐藏属性

有些特点在真实足球里也看不见，只能从表现中感觉出来：**稳定性**（时好时坏）、**大场面表现**、**受伤倾向**、**职业态度**（影响成长和训练）、**性格**（好不好管、会不会闹转会）。

- **A. 这些不直接显示，但相处时间越长，教练组的评语越准（「训练非常刻苦」「大赛容易紧张」）**（推荐）
- B. 全部直接显示成数字
- C. 完全看不到，连评语也没有

推荐理由：和第 4 题一个思路：不是查表，是「了解一个人」。也给以后的事件系统（教练个人生活、更衣室）留了素材。

## 6. 招牌动作和打法习惯（对应品味清单「踩单车、双脚触球」）

- **A. 两种都要：每个球员有 0～3 个招牌动作，外加 0～3 个打法习惯**（推荐）
- B. 只要招牌动作
- C. 都不要，全部由能力值决定

两者的区别：

- **招牌动作**是他会用的花样，比如踩单车、双脚拨球、马赛回旋、挑球过人、假射真扣、外脚背传球、电梯球任意球、手抛球快速发动进攻（门将）。没有这个招牌动作的球员不会用这个动作；有的人用起来成功率更高。
- **打法习惯**是他喜欢怎么踢，比如喜欢内切射门、喜欢一脚出球、喜欢插上到禁区、喜欢下底传中、喜欢远射、喜欢回撤拿球。战术指令可以压住习惯，但球员累了或比赛紧张时，习惯会冒出来。

推荐理由：这是「不同球员过人方式看得出区别」（品味清单）的直接做法，也是让球员有个性、不只是一堆数字的最好办法。2D 阶段先用文字和小图标表示动作名称，3D（阶段 5）做成真正的动作。

## 7. 惯用脚

- **A. 每人有惯用脚，另有一项「逆足」能力决定非惯用脚的水平**（推荐）
- B. 只记惯用脚是左还是右，非惯用脚统一打折
- C. 不区分

推荐理由：左脚球员踢右边锋内切、右脚球员踢左边锋，是阵型和打法里很重要的一部分；逆足强的球员更难防。

## 8. 能踢哪些位置

- **A. 每个位置单独有一个熟悉度（从「陌生」到「专精」），可以通过训练慢慢学新位置**（推荐）
- B. 每人一个主位置加最多两个副位置，其他位置都一样差
- C. 只有一个位置

推荐理由：品味清单里你想「把球员放到任意位置」。熟悉度让这件事有代价也有收益：中后卫临时踢后腰会差一点，但不会离谱；练久了能变成新位置。

## 9. 别的球队的球员，你能看得多清楚？

- **A. 自己队的准确；别的队显示一个范围（比如「良好～出色」），交手过、同一个联赛的球队看得更清楚**（推荐）
- B. 所有球员都看得一清二楚
- C. 必须派球探才能看到任何能力（完整球探系统）

推荐理由：A 让转会有「赌一把」的感觉，又不用先做球探系统。完整的球探网络在路线图的功能分档里是第二档（正式版），以后再在 A 的基础上加。

## 附表：第 1 题推荐的能力列表

每一项都写了它在比赛里管什么。名字以后还能改。

### 技术（10 项）

| 能力 | 在比赛里管什么 |
|---|---|
| 短传 | 短距离传球的准确度和力量控制 |
| 长传 | 长距离传球、转移、打身后的准确度 |
| 传中 | 从边路往禁区传球的准确度 |
| 射术 | 禁区内射门的准确度 |
| 远射 | 禁区外射门的准确度和力量 |
| 盘带 | 带球时球离脚多远、过人成功率 |
| 停球 | 接球是否稳，第一脚能不能把球停到好位置 |
| 头球 | 争顶成功后顶向哪里、准不准 |
| 抢断 | 上抢成功率，以及会不会犯规 |
| 定位球 | 任意球、角球、点球的质量 |

### 意识（8 项）

| 能力 | 在比赛里管什么 |
|---|---|
| 视野 | 能「看到」多远、多少条传球路线；低的人只会看见身边的队友 |
| 决断 | 选择对不对：该传就传、该射就射，以及做决定快不快 |
| 无球跑动 | 进攻时会不会找空当、什么时候插上（二过一、打身后） |
| 防守站位 | 防守时站得对不对、防线能不能保持整齐（造越位） |
| 镇定 | 被逼抢、关键时刻时动作会不会变形 |
| 拼劲 | 争抢、对抗的积极程度；高的人也更容易吃牌 |
| 团队意识 | 愿不愿意按战术踢、愿不愿意传给位置更好的人 |
| 勤奋 | 无球时跑不跑：回追、压迫、补位 |

### 身体（6 项）

| 能力 | 在比赛里管什么 |
|---|---|
| 速度 | 最高速度 |
| 加速 | 起步多快达到最高速度 |
| 耐力 | 体能下降多快；累了以后所有能力都会打折 |
| 强壮 | 身体对抗、护球 |
| 灵活 | 转身、变向快不快 |
| 弹跳 | 争顶高度（身高另外记，和弹跳一起算） |

另外每人记：身高、惯用脚和逆足（第 7 题）、各位置熟悉度（第 8 题）、隐藏属性（第 5 题）、招牌动作和打法习惯（第 6 题）。

### 门将另有（7 项）

| 能力 | 在比赛里管什么 |
|---|---|
| 反应 | 近距离扑救 |
| 扑救范围 | 能扑到多远的球 |
| 手形 | 接得住还是脱手 |
| 高空球 | 出来摘传中球 |
| 出击 | 什么时候离开球门、单刀时怎么封堵 |
| 门将站位 | 站位角度是否合理 |
| 出球 | 手抛球和脚下传球的质量 |

门将也有上面的意识和身体能力（比如镇定、加速），技术项里只用得上短传、长传和停球。
