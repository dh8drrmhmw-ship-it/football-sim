# 立项

## 一句话

一款比 FM 更真实的足球经理游戏：**没有神阵，对手教练会动脑子，你的每次换人都算数。**

## 为什么做

FM（Football Manager）多年没有像样的竞品，每年换皮、更新数据库，老玩家的不满越积越多。立项时整理的玩家不满（来自项目发起人，本身是 FM 玩家）：

1. **神阵**：总有某几套阵型胜率特别高，研究出来就能一直赢。
2. **比赛以外很单调**：收邮件、赛后采访、临场指挥一成不变；工资挣了花不出去。
3. **玩久了都差不多**：换人、改阵型对比赛影响不大。
4. **bug 多，对手教练很笨**：AI 教练不会灵活换人、不会调整，不真实。

FM 的比赛引擎在足球逻辑上（跑位、配合、节奏）被很多玩家认为不如十几年前的实况足球 8。

## 核心卖点

1. **比赛像足球**：22 个球员各自判断跑位、传球、压迫，战术通过改变球员的行为起作用。
2. **没有神阵**：每种打法都有克制它的打法；上线前用电脑把所有战术两两对打几万场，提前找出并修掉无敌战术。
3. **会动脑子的对手**：AI 教练在比赛中会推演换人和战术调整的效果，落后会压上，被压制会变阵，球员累了会换人。
4. **每次换人都看得见效果**：赛后分析告诉你哪个调整起了什么作用。

比赛以外的丰富度（事件系统、教练个人生活）是第二步的卖点，见路线图。

## 目标玩家

- 对 FM 不满意、但找不到替代品的老玩家（首要）
- 喜欢实况足球、想要更真实比赛的经理游戏玩家
- 语言：中文和英文同时支持

## 平台

1. **网页**：开发全程都是网页游戏，Mac 和手机浏览器都能直接玩，公开试玩也用网页链接。
2. **Steam（Windows、Mac）**：以抢先体验（Early Access）方式上线，这是收费渠道。
3. 海外手机应用商店：以后再看。

## 明确不做（除非改立项）

- **不用真实球员、真实队名和队徽**。国家和城市用真实的，联赛、球队、球员由程序生成。
- **不官方发布真实名单补丁**。提供编辑器，社区自己做。
- **不上国内应用商店和微信小游戏**：需要版号，个人拿不到。
- **前期不做联机**。
- **不照搬任何商业游戏的代码和素材**（实况、FM 等），只学习玩法思路。
- **不追求实况 8 的动作捕捉水平**。3D 目标是接近 PS2 时代实况的观感，2D 始终保底。

## 成功标准

- **从零到一（约第 7 个月）**：网页版公开试玩，至少 300 人玩过，其中五分之一玩完一个赛季，有人主动问「什么时候出完整版」。这些是经验值，不是硬规则。
- **抢先体验（约第 16 个月）**：Steam 上线前愿望单达到几千。
