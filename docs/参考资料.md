# 参考资料

用到任何第三方代码、素材、数据前，先在这里登记许可证。规则见决策记录 D-011。
「状态」：参考 = 只看思路；使用 = 代码、素材或数据进入项目；待确认 = 许可证还没核实。

## 比赛模拟

| 项目 | 内容 | 许可证 | 状态 |
|---|---|---|---|
| [Google Research Football](https://github.com/google-research/football) | 3D 物理足球模拟，底层来自开源游戏 Gameplay Football | Apache 2.0 | 参考：球和球员的物理、22 人比赛逻辑 |
| [helios-base](https://github.com/helios-base/helios-base) | RoboCup 2D 冠军级球队代码 | 待确认 | 参考：阵型算法、跑位、传球选择 |
| [Cyrus2D](https://github.com/cyrus2d/cyrus2dbase) | 基于 helios-base | 待确认 | 参考 |
| [CLS / py2d](https://github.com/CLSFramework/py2d) | RoboCup 2D 的 Python 框架 | MIT | 参考 |
