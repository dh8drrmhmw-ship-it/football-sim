# 参考资料

用到任何第三方代码、素材、数据前，先在这里登记许可证。规则见决策记录 D-011。
「状态」：参考 = 只看思路；使用 = 代码、素材或数据进入项目；待确认 = 许可证还没核实。

## 算法（我们自己写的代码，只借用公开的算法）

| 算法 | 用在哪 | 许可证 | 状态 |
|---|---|---|---|
| [xoshiro128\*\*](https://prng.di.unimi.it/)（Blackman、Vigna，2018） | 固定种子随机数 `src/core/rng.ts` | 公有领域（CC0），参考实现可随意使用 | 使用：按论文和参考实现自己写，和官方 C 版本逐个数核对 |
| splitmix32 / MurmurHash3 的混合步骤（Austin Appleby） | 随机数种子展开、校验码 `src/core/hash.ts` | 公有领域 | 使用：自己写 |
| 泰勒级数、Cody–Waite 区间约化 | 确定性数学函数 `src/core/math.ts` | 数学方法，无版权 | 使用：常数由高精度十进制自己推出 |
